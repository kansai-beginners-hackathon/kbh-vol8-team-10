# 終電データ カバレッジ

最終更新: 2026-08-29（`lib/localData.ts` で私鉄 5 社を接続、叡電 鞍馬線を出町柳直通に統合した後）

「ハブ（京都市内 7 駅）→ 自宅駅」の終電をどこまで出せるかを、事業者・路線ごとにまとめる。

- **ローカル JSON** = `data/*-last-trains.json`（サスケくん作成の静的データ）。`lib/localData.ts` が 6 ファイルを 1 組にまとめ、`lib/lastTrain.ts` の `lastTrainBetween` で乗換なしの終電を解く
- **Transit** = Transit API（`https://api.transit.ls8h.com`）の `plan`（`type=arrival&time=26:00`）。詳細は [Transit_API_ガイド.md](./Transit_API_ガイド.md) 6 章
- 判定の流れは `lib/resolveLastTrain.ts`（ローカル → Transit → unavailable）

## 1. ひと目で

**京都市内のハブから電車一本で帰る範囲は、ほぼ穴なく出せる。**

| 状態 | 路線 |
|---|---|
| ✅ 直通で出せる | 地下鉄、叡電（鞍馬線含む）、嵐電、京阪（〜樟葉はローカル、以南は Transit）、阪急（〜高槻市）、近鉄（普通のみ）、JR（京都発、Transit） |
| ⚠️ 一部だけ | 京阪京津線（東西線直通、乗換 1 回前提） |
| ❌ 出せない | 阪急 大阪梅田方面（JR で代替中）、京都市営バス、府外私鉄（阪神・南海 等） |

残っている穴は実質 1 つ:

- **阪急で大阪梅田まで直通** — Transit の阪急 feed が京都線途中で切れていて 0 件。ローカルも高槻市まで。JR 京都→大阪 23:58 で代替できているので、ユーザー視点では「梅田に帰れる終電」は出ている

| データ | 読んでいる場所 | Planner に反映 |

| `kyoto-city-bus-direct-8stations.json` | 未 import | ❌ |

`lib/localData.ts` のポイント:

- `lastTrainBetween` は駅を名前で 1 件だけ引くので、複数社に同じ名前の駅（京都=地下鉄+近鉄、出町柳=叡電+京阪、西院=嵐電+阪急、竹田・十条=地下鉄+近鉄）は `lines[]` を 1 駅にまとめる

## 6. 注意点

- 阪急・京阪・近鉄のローカルは **普通列車ベース**。深夜の急行・特急で帰れるケースは実際より早い時刻を出す（「間に合わない」側に倒れるので安全側）
- Transit の `type=last` は使わない（翌朝着経路を返す）。必ず `type=arrival`
- 同名駅は feed ごとに別 ID（出町柳＝京阪 / 叡電、大阪梅田＝阪急 / 阪神）。`suggestStationId` の `preferFeeds` で選ぶ
- 叡電・地下鉄・近鉄は Transit の `plan` が壊れているので、ローカルに無い区間（乗換あり）は出せない
