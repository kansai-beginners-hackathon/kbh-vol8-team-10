# 実装計画 — 終電ロジック（乗換なし / 乗換あり / フロント接続）

作成: 2026-08-29
対象: `lib/` `data/` `components/Planner.tsx`
関連: `docs/Transit_API_ガイド.md`（API の癖はここに全部書いてある）

> この計画は「今あるデータで動くものを出す」ための計画です。
> データのカバー率（私鉄の終電 JSON・候補地→ハブの所要時間）は別メンバー担当なので、ここでは扱いません。

---

## 1. ゴール

メンバー全員の最寄り駅を入れると、候補地ごとに「全員が終電で帰れる最も遅い解散時刻」が**実データで**出る。

今は `components/Planner.tsx` が `data/network.ts` のモック（手打ちのダミー値）を読んでいる。これを実データに置き換える。

---

## 2. 全体の形

```
候補地 Venue ──toHub[hub]={transitMin, lastDepart}──▶ ハブ Hub(7) ──Route{transferMin, last}──▶ 自宅駅
                    ↑ 別メンバーのデータ（今はモック）              ↑ ★ここを自動化する
```

`lib/calc.ts` の `rankVenues()` は `STATIONS: Record<自宅駅名, Station>` を受け取って順位を出す。**この式は変えない。** 変えるのは `STATIONS` の作り方だけ。

「ハブ → 自宅駅の終電」は 3 層で解く：

| 層 | 条件 | 情報源 | 精度 | 担当タスク |
|---|---|---|---|---|
| ① 乗換なし | ハブと自宅駅が同じ路線 | ローカル JSON（`data/subway-*.json`） | 高 | **タスク1（完了）** |
| ② 乗換あり | ①で出ない | Transit API `plan type=arrival&time=26:00` | 乗換1回まで高、2回以上は参考値 | **タスク2** |
| ③ どちらでも出ない | Transit がデータを持っていない | — | 「対応予定」表示 | タスク2で unavailable として返す |

①で Transit が持っていないもの（近鉄・叡電・阪急梅田方面など）は、さすけくんの JSON が同じ形で増えれば自然に①で解けるようになる。**本計画では考慮しない。**

## 5. 決定事項（レビューで確定したもの）

| 項目 | 決定 | 理由 |
|---|---|---|
| 終電検索の `type` | **`arrival` + `time=26:00`**。`type=last` は使わない | `last` は「いつか着く便」を返し、翌朝接続や真の終電の見逃しが起きる（ガイド 6-3） |
| 「終電の嘘」（掲示上の最終との差） | **作らない** | 要件定義 §3/§5/§7 の記述は古い。`Route.posted/postedTo`・`lieOf()` は削除 |
| 同じ駅（電車不要）の人 | **終電の制約から外す**。Transit は呼ばない | 呼んでも 422 `samePlace`。意味の無い結果を出す危険を型で塞ぐ |
| Transit でも出ない区間 | **「対応予定」表示**。今出せる範囲で勝負 | feed が壊れている区間に時間を使わない |
| ハブの Transit 出発地 | **`geo:緯度,経度`** | ハブは複数事業者の駅の集合（出町柳＝京阪+叡電）。座標で渡して Transit に選ばせる |
| `Route.last` の型 | **`string \| null`**（null = 制約なし） | 既存 `HubCell.lastDepart: null` = 無制限 と同じ流儀 |
| 対応予定のメンバー | **順位計算から除外**し、別枠で「◯◯さんは対応予定」表示 | deadMember 扱いにすると全候補地が ❌ になる |
| 日付 | 今日。`dayType` は土日判定のみ（祝日なし） | Planner に日付入力が無い |

## 6. モックのまま残るもの（本計画の完了条件に含めない）

- `VENUES[].toHub` の `transitMin` / `lastDepart`（候補地→ハブの所要と最終）— 別メンバー。**ここがモックのままだと順位は正確にならない**
- 私鉄の乗換なし JSON — さすけくん
- `DEFAULT_MEMBERS` の駅名（デモ用）— 実データで出せる駅に差し替えるのは 3b の最後に判断
